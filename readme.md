# 告白气球 🎈 Cupid Edition

> 爱神丘比特（Cupid）在线营业：先安放你的心事，再陪你把爱说出去。

一个纯前端的「爱情表白平台」：把心事整理清楚（丘比特之箭五支箭），把爱意做成一颗会飞、会唱歌的告白气球（可分享的单文件 HTML 页面），内置跨学科知识库（心理 / 沟通 / 法律 / 社会 / 哲学 / 家庭 / 性学 / 多元关系），尊重每一种关系形态。

## ✨ 功能一览

| 模块 | 说明 |
| --- | --- |
| 🏹 丘比特之箭 | 五步心事整理：安放心事 → 写下你们 → 校准信号 → 缘分推演 → 爱的台词。多心动对象、多元关系友好 |
| 💗 爱的台词 | 真诚 / 灵动 / 勇气三档语气 × 表白 / 推进 / 回复 / 修复 / 退场五个场景，成品话术一键复制，附积极 / 含糊 / 沉默三分支预案 |
| 🎈 告白气球工作台 | 12 款气球主题 + 背景音乐，生成独立 HTML 告白页，微信 / QQ 直接发送 |

| 🛡 安全底线 | 对方说不就收弓 · 不窥探人心 · 暴力 / 跟踪 / 诈骗情境只做安全与法律转介 |

## 🚀 启动方式

### 方式一：本地服务器（推荐）

任选其一，在 `告白气球` 目录下执行：

```bash
# Python（推荐，Windows 自带）
python -m http.server 8787

# Node.js
npx serve -l 8787 .
# 或
npx http-server -p 8787 .
```

然后浏览器打开：<http://localhost:8787>

### 方式二：直接双击打开

直接双击 `index.html` 也能运行——本项目无构建步骤、无后端、无外部依赖。

> 注意：个别浏览器对 `file://` 协议限制剪贴板 API，若「复制」按钮无效，请改用方式一。

## 🎈 生成告白气球怎么发给 TA

1. 进入「告白气球」页，填写称呼 / 标题 / 情书（每行一句，说具体的小事）；
2. （可选）上传一首本地音乐，或粘贴音乐直链；
3. 选一款气球风格，右侧实时预览；
4. 点「下载告白气球」，把得到的 `给你的告白气球.html` 直接发给 TA——单文件、离线可开，本地音乐会一并打包进去。

生成的页面自带右下角 ♪ 音乐开关；浏览器若拦截自动播放，TA 点击页面任意位置即会响起。
